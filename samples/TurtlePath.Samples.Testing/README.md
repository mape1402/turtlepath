# TurtlePath Testing Sample

This sample shows how to use the TurtlePath testing packages from a real test project.

Covered scenarios:

- manual handler unit test without mock setup
- automation integration test through Pelican and SQLite
- query integration test with seeded in-memory storage
- exception handling assertions
- one-shot job execution

Packages demonstrated:

- `TurtlePath.Testing`
- `TurtlePath.Testing.EntityFrameworkCore`
